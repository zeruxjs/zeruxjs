Framework API overview

Navigate the public contracts by responsibility, then inspect exact import paths.

↗ View Markdown

Start with a contract#

  • Configuration reference: project structure, hosts, service startup and runtime settings.
  • Request context: params, query, state, services and response access.
  • Plugin API: registrations and generation ownership.
  • Response API: cache policies, streams, redirects and deliberate errors.
  • Workers: startup cleanup and thread-pool tasks.
  • Fetch bridge: interoperable Web Request/Response handlers.
  • Template variables: bounded interpolation and escaping.

Import paths#

Use public export-map entries. Private source paths and generated dist internals are not stable application imports.
