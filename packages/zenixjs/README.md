# zenixjs

Placeholder package for future development.

This package is a placeholder for the future Zenix CMS. This package exports only `version` and `status` metadata (`"placeholder"`). It does not include a CMS, admin dashboard, authentication, or a project generator.

## Development

Run `npm run build` from this package directory.
